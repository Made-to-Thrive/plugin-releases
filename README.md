# Made to Thrive Plugin Releases

This public repository is the distribution endpoint for Made to Thrive WordPress plugins.

- GitHub Releases contain immutable installable ZIP files and SHA-256 checksum files.
- `plugins/<slug>.json` contains the current WordPress update metadata for a plugin.
- Manifests are published only after their matching release assets have been verified.

Development source, issue planning, client information, credentials, and unreleased code belong in the private `made-to-thrive/mtt-plugins` repository and must never be committed here.

Public release ZIPs are intentionally downloadable without authentication. Client WordPress sites do not require GitHub credentials.
